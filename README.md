# Записная книжка на Python

Простая консольная программа для хранения контактов (имя и телефон), учебный проект на Python.

## Функции

- **Добавить номер** — ввести имя и телефон, контакт сохраняется в список
- **Все контакты** — вывести список всех сохранённых контактов с их номерами (индексами)
- **Удалить контакт** — удалить контакт по индексу
  - защита от пустого списка контактов
  - защита от неверного индекса
  - защита от нечислового ввода
- **Выход** — завершить программу

## Как запустить

```bash
python knijka.py
```

После запуска в консоли появится меню, где нужно ввести номер пункта.

## Технологии

- Python 3
- Список словарей для хранения контактов
- `try` / `except` для обработки ошибок ввода
